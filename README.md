# Speak Up — English Reading & Speaking Prompter

A minimalist, high-performance web application designed to help English learners practice reading out loud with a moving teleprompter.

## ✨ Features

- **Responsive Design**: Flawlessly adapts to any screen:
  - 🖥️ Large Monitors & Ultrawide displays (centered, distraction-free reading studio)
  - 💻 Laptops (comfortable viewing distance, keyboard shortcuts)
  - 📱 Tablets & Mobile phones (dynamic text chunking, generous breathing room, touch-friendly 44px+ controls)
- **Fluid Reading State Preservation**: Resizing the window or rotating mobile screens dynamically recalculates line breaks while preserving the user's exact reading word position (`wordPos`).
- **Speed Control**: Adjustable teleprompter pace from 40 to 260 words per minute (WPM).
- **Audio Cue**: Speech Synthesis intro ("Speak fast and clear") to pace each reading session.
- **Zero-backend / Serverless**: 100% client-side HTML5, CSS3, and modern vanilla JavaScript.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `Space` | Start / Pause scrolling |
| `R` | Restart reading from beginning |
| `Esc` | Return to topics list |
| `↑` / `→` | Increase speed by 5 WPM |
| `↓` / `←` | Decrease speed by 5 WPM |

## 🚀 Getting Started

Simply open `index.html` or `Speak Up.html` in any modern web browser.
